Primera versión pública de **BISUNI v2**, un sistema de control escolar universitario. Tiene tres piezas:
- una app de escritorio para control escolar y profesores;
- un portal web para alumnos y aspirantes;
- una base de datos PostgreSQL que comparten.

## Qué incluye
- **Ciclo escolar completo:**
  - periodos con convocatoria;
  - admisión de aspirantes con matrícula;
  - grupos, materias y horarios sin choques;
  - calificaciones con cierre de actas;
  - pase de lista;
  - reinscripción al semestre siguiente y egreso.
- **Control escolar** (escritorio):
  - panel con alertas;
  - carreras, materias, profesores y usuarios;
  - bajas, reingresos y egresos;
  - contraseñas temporales;
  - avisos;
  - bitácora de cambios.
- **Profesores** (escritorio): sus clases, horario y grupos; captura de calificaciones; actas; asistencia; avisos
  para sus grupos.
- **Alumnos** (web):
  - avisos y alertas de faltas;
  - calificaciones, kárdex con avance de créditos, horario, asistencia y profesores;
  - constancia, kárdex y boleta en PDF.
- **Aspirantes** (web): registro en la convocatoria y consulta de estatus con CURP y folio.

## Descargas
| Archivo | Qué es |
|---|---|
| `BISUNI-Escritorio-2.0.0-windows-x64.zip` | App de escritorio para Windows 10/11 con su propio Java. Descomprime, configura `bisuni.properties` (ver `LEEME.txt`) y abre `BISUNI.exe` |
| `BISUNI-BaseDeDatos-2.0.0.zip` | Esquema SQL, datos de demostración y scripts para crear la base y el primer administrador |

El portal web se instala desde el código fuente con Node.js 20.9+. La
[guía de instalación](https://github.com/Yamato6/BISUNI-v2/blob/main/docs/instalacion.md) cubre las tres piezas,
tanto en demostración como en una instalación real.

## Requisitos
- PostgreSQL 17 o superior.
- Escritorio: Windows con el zip; en otros sistemas, Java 21+ y el código fuente (`./mvnw javafx:run`).
- Web: Node.js 20.9+.
